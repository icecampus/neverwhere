# B-repGeneratedLandscape

_Вынесено из `AGENTS.md` (2026-09-06): корневой файл — компактная входная точка, подробности подсистем живут в `docs/`. Правя соответствующий код, обновляй **этот** документ._

**B-repGeneratedLandscape.** Стенд B-rep конвейера поверх изометрической сетки (каркас — копия FencePathPlayground: sokol_app + ImGui, `GridRenderer` без изменений, камера `Camera2D`/`DiamondIsometry`, сцена в точках, `--shot` через glReadPixels): LMB-драг красит вертекс-ноды 25×25 (`NodeField` + Брезенхэм `paintNodeLine` между событиями мыши — против «дырявых росчерков»), Ctrl+LMB/чекбокс — стирание, RMB — пан, wheel — зум. Генерация — **плейграундный форк** `src/libs/landscape_mesh`: `BrepMesh.h/.cpp` + `BrepWallStyle.h/.cpp` рядом с main.cpp (бит-в-бит копия на момент форка, namespace `brepmesh`; линковка `landscape_core` + `FastNoise2` напрямую, `landscape_mesh` в LIBS нет) — эксперименты с хайграундом идут только в форке, редактор (`render_core::CyclopeanRenderer`) и другие плейграунды не затрагиваются. Геометрия — `BrepRenderer` (bbox нод с маржой 1 → `solidMaskFromNodes` → `composeSolidMaskMesh`, но z печётся в вершину с **константным** анкером `kZFar=100000`/`kZScale=1/200000`, как у GridRenderer, а не per-frame `z_range`): вершина `BrepVertex` (field xy + baked z, нормаль = `litWallNormal` для стен, world xyz, цвет квада), пайплайн TRIANGLES с LESS_EQUAL + depth write, без бленда и cull'а (квады в обоих вайндингах). Два dirty-флага: `meshDirty` — дебаунс 0.3 с в композер, `streamDirty` — мгновенная перезапечка вершин при смене `heightScale` (слайдер живой); один `sg_update_buffer` на ребилд. Шейдеры в трёх диалектах (GLSL/HLSL/MSL): FS — base=цвет квада → ambient/diffuse/Blinn/gamma → PBR-lite материал (порт из SDFWithMaterialLandscape: `matuv`, трипланар альбедо с весами^4, AO душит ambient, roughness душит spec; мип-цепочка CPU + REPEAT LINEAR_MIPMAP_LINEAR aniso×8, плейсхолдеры 1×1), **отличие — нормал-мапа/AO/roughness сэмплятся по доминантной оси нормали** (box-mapping: у B-rep главная поверхность — вертикальные стены, top-проекция полосила бы); при нулевых силах — бит-в-бит чистый цвет квада, промах загрузки карт зануляет силы. Наборы материалов — **`resources/textures/<vendor>/<name>/`** (имя листового каталога = префикс файлов = имя сета): 8 Poly Haven-паков в `polyhaven/` (marble_cliff_01/03/04, aerial_rocks_02, cliff_side, dark_rock_02, dry_riverbed_rock, rock_04; `textures/*` из `.blend.zip` плоско в каталог сета) + ambientCG Rock064 в `ambientcg/Rock064` (переименован в конвенцию Ground061: `Rock064_Color/NormalGL/AmbientOcclusion/Roughness.png` — единственный сет с AO-картой). Лоадер пробует обе конвенции имён (`<set>_Color/_NormalGL/...` и `<set>_diff_4k/_nor_gl_4k/...` **плюс `_2k`-варианты** — marble_cliff_03 двухкиловый) по общей таблице `kMatCandidates`; EXR stb не читает — `nor_gl`/`rough` конвертируются в PNG рядом с источниками (разовая конвертация scratch-скриптом, не коммитится: venv с OpenEXR+Pillow, без колор-менеджмента, clamp→8bit; у dark_rock_02 нормаль лежит в RGBA-канале — альфа отбрасывается). `loadMaterialMaps` возвращает **битмаску каналов** (bit0 color, bit1 normal, bit2 AO, bit3 rough), файловый двойник без GPU — `probeMaterialMaps` (пикер им сканирует `resources/textures` на два уровня — `<vendor>/<name>/` — подхватывая и Ground061; smoke — проверяет дефолтный сет). `matuv` aspect-aware: V-фактор тайлинга (2 для 2:1 сетов вроде Ground061, 1 для квадратных) меряется по аспекту карты при загрузке и едет в `params1.y`. Травяной верх — отдельный канал (FS view 4, `grass_color`, тот же мипмап-REPEAT-сэмплер): FS миксует тайлящуюся текстуру (`resources/textures/grass.png`, `loadGrassMap`) поверх альбедо по весу `smoothstep(0.75, 0.92, n.y)` от shading-нормали **до** normal-детали (стены с горизонтальной `litWallNormal` остаются камнем, верх плато зеленеет, кромка мягко заезжает на rim), заодно гася rock normal-detail множителем `(1−grassW)`; сила/тайлинг — `params4.xy` (0 = бит-в-бит выкл), UI-слайдеры «Grass»/«Grass tiling», CLI `--grass=`/`--grass-tiling=`. **Многоуровневость:** нода хранит уровень плато 0..`kMaxNodeLevel`(3) (`NodeField`, радио «Paint level» у кисти, Ctrl/erase — 0); `rebuildMesh` композитит по бэнду на уровень (маска `value ≥ k` — подмножество предыдущей, база `(k−1)·H` → верх `k·H`, общий union-bbox → один origin; hfrac деформации клампится в 1 выше H, поэтому верхние бэнды целиком «ездят» на рельефе, сшивка террас сохраняется). **Bake-деформация (stream-only, живые слайдеры):** каждая вершина смещается чистой функцией исходной мировой позиции и heightFrac (`brepDeformVertex`, value-noise 2 октавы) — рельеф верха и блуждание кромки (wobble), обе ×hfrac (подошва заземлена; общие вершины смещаются одинаково — швы целы по построению); верхним квадам — гладкие нормали из градиента рельефа. **Макро-профиль стены** (`wallProfileOffset` в форке композера): batter (отвал) + foot flare + strata-полки — применяется к базовым рядам стены ДО стилевого вытеснения и **вне** анти-фолд клемпа (~0.7·spacing задавил бы профиль), всё спиннено на гребне (0 при heightT=1), фаза полок — функция мировой позиции (общие вершины сегментов смещаются одинаково). **Осыпь (talus):** апрон-юбка от смещённого ряда стены (высота `talusHeightFrac`·H) до земли, верхний край сшит с бэндом бит-в-бит (переиспользован displaced-ряд), форк-маркер `MeshQuad.talus`. **Вершинные каналы затенения** (attr 4 `BrepVertex.reliefT/talusH` — заменили первые юниформные гейты, т.к. многоуровнево-безопасны): FS светлеет гребни рельефа (`base *= 1+reliefT·0.18`) и темнит+гладит подошву осыпи к линии контакта. Дефолт сил при выборе сета: **albedo/normal/roughness=1, AO=0.5 если у сета есть AO-карта иначе 0, tiling 0.35** — стены и верх полностью покрыты материалом, от композера только геометрия (запечённые цвета — фолбэк). UI: генерация (raisedHeight 0.5–8 дефолт 3.0 — **высота одного уровня**, rockSeed/Amplitude, cornerBevel, subdivH/V 4–16, rockEnabled, Wall Style {Cyclopean, BlockCliff}, профиль Batter/Foot flare/Ledges/Talus, heightScale, деформация relief/wobble — живые), материал (**комбо `Set` — переключение сета на лету**, tiling/albedo/normal/AO/roughness + Reload, Grass/Grass tiling), статистика (квады, ms, seams). CLI: `--shot=`, `--smoke`, `--no-ui`, `--zoom=`, `--center=`, `--nodes="x,y;…"`, `--height=`, `--seed=`, `--style=cyclopean|block`, `--mat-dir=`, `--mat-set=`, `--mat-tiling=`, `--grass=`, `--grass-tiling=`, `--relief=`/`--relief-wavelength=`, `--wobble=`/`--wobble-wavelength=`, `--batter=`, `--foot-flare=`, `--ledges=`, `--talus=`, `--bevel=`, `--nodes2=`/`--nodes3=`; smoke (`PlaygroundSmokeTest.cpp`) — Cyclopean/BlockCliff compose (seams, top/wall-квады, outward-нормали), запёчка (z-контракт, bbox), Брезенхэм, наличие marble_cliff_01 в resources/textures/polyhaven (вкл. конвертированные PNG) + `probeMaterialMaps` по нему, наличие/декодируемость (stb) grass.png, деформация (identity/determinism/grounded/bounds/не плоская), профиль (crest pinned / foot battered / ledges), talus (сшивка/флаг), multi-level (швы обоих бэндов, топ на 2H, стены от 1H). Subdivs ≥16 — при 5×6 кладка не читается.
