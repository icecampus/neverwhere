# ShapemlPlayground + shapeml_ref (ShapeML, GPL3v3)

_Вынесено из `AGENTS.md` (2026-09-06): корневой файл — компактная входная точка, подробности подсистем живут в `docs/`. Правя соответствующий код, обновляй **этот** документ._

`src/apps/ShapemlPlayground` — обозреватель возможностей [ShapeML](https://github.com/stefalie/shapeml) (shape grammars / CGA-подобное процедурное моделирование: extrude/split/roof по straight skeleton). Список `.shp`: сначала собственные грамматики из `src/apps/ShapemlPlayground/grammars/` (`stone_wall.shp` — каменная кладка с перевязкой/цоколем/капителью: trimPlane-фаски «подушей», вероятностные finish-правила цвета, выпадающие камни; `christmas_tree.shp` — казуальная ёлочка: ствол + ярусы фасеточных конусов с рампой зелени по `index`, кольца шаров через `repeat`+`rotateY` вокруг оси, звезда — `polygon`+`extrude`, снежная подложка; `fence.shp` — модульная ограда «казуальная готика»: каменные столбы из крупных валунов (стопка pillow-bevel блоков с yaw-джиттером и случайными сколами-сечениями, двухступенчатый цоколь, мох у подножия) + черепичная крышка (тёмный 4-конус-сердечник + 2×2 сланцевые плитки на скат с реальной толщиной, укладка внахлёст; **4-сегментный coneFlat рождается с гранями по осям scope — поворачивать на 45° НЕ надо**) + кованая секция (два рельса, прутья с копьями через один по `index % 2`, кольца-торы между прутьями, лёгкий случайный наклон прутьев), состаренный металл — железо/медь-вердигрис переключаются `param metal` (финиали столбов — тот же металл: шар у обычного, шпиль у углового/высокого), акценты ржавчины/голой меди вероятностными правилами; `param piece` выбирает деталь под экспорт: столб / угловой столб / секция / демо-прогон; все ручки — `param`), затем стоковые из `external/shapeml/grammars` (override `--dir`), живые контролы `param`-параметров грамматики, seed, auto-derive с debounce 0.3 с, orbit-камера (как StoneCube), экспорт OBJ их `Exporter`'ом (в `tmp/shapeml_export/`). CLI: `--smoke` (parse+derive всех грамматик директории, TEST PASS/FAIL; ~1.5 мин в Debug — stress-грамматики `test_noise_2D` (65k листьев) и `test_noise_3D` (247k листьев / 5.9M вершин, ~5 ч в Debug) пропускаются, для них — явный `--grammar`) / `--shot` / `--seed` / `--grammar <имя|путь>` / `--export <dir> [--export-name <stem>] [--param name=value]...` (пакетный OBJ+MTL экспорт одной грамматики с оверрайдами параметров, one-shot с TEST PASS/FAIL; stem передаётся их `Exporter`'у БЕЗ расширения — он сам дописывает .obj/.mtl, а UI-кнопка Export передаёт stem+".obj" и потому пишет `fence.obj.obj`). Рендер — минимальный sokol-пайплайн (GLCORE-исключение, шаблон StoneCube): цвет материала × diffuse-текстура (stb_image, белый 1×1 fallback), lambert + hemisphere ambient, дравы сгруппированы по текстуре. Мост к библиотеке — `GrammarHost` (единственный TU с shapeml-инклюдами, pimpl): `Parser::Parse` (**у них true = ошибка**; base_path/file_name выставляет сам — ассеты грамматик резолвятся от файла грамматики) → `Interpreter::Init/Derive` (обязательно с world-octree `Octree(Vec3::Zero(), 1000)` — occlusion-грамматики вроде castle.shp крашатся без него) → листья через `LeafConstVisitor` (фильтр `terminal && visible && mesh && !Empty`) → `FillRenderBuffer` + `MeshWorldTrafo`/`MeshNormalMatrix` (меши в unit-space 0..1, кэшируются по указателю — инстансы делят меш).

Библиотека — submodule `external/shapeml` + обёртка `src/libs/shapeml_ref` (свой CMakeLists: их билд несовместим с CMake 4.x — `cmake_minimum 3.0`, а viewer/glfw нам не нужны; собираются только core + surface_mesh, C++17, `-w` + force-include `cstdint` — их `vector_types.h` полагается на транзитивный `<cstdint>`, пропавший в GCC 13+). **Лицензия GPL3v3:** `shapeml_ref` линковать ТОЛЬКО в ShapemlPlayground (внутренний инструмент, не распространяется); в EpicMapEditor / EpicGameClient / общие libs — нельзя, статическая линковка GPL делает производный бинарь GPL при распространении. Грабли: `Bool` — макрос X11 (`#define Bool int`, течёт из sokol_app.h) — в enum плейграунда значение названо `Boolean`. Сам таргет ShapemlPlayground тоже поднят на C++17 (не проектный C++20): `GrammarHost.cpp` тянет shapeml-заголовки с бандленным Eigen 3.3.7, а его `std::result_of` выкинут из libc++ в C++20 — на macOS без этого не собирается (на MSVC `result_of` ещё жив). В грамматиках: splitX/Y/Z требуют меша на шейпе (ставить `quad` перед split); `color()` обязан стоять inline в правиле, закрывающемся терминалом — «голое» color-правило в середине op-string теряет материал; `extrude()` растёт в +y локального scope, поэтому стены строятся «лёжа» и ставятся `rotateX(-90)` (+`rotateZ(180)` лицом к дефолтной камере); подложки нельзя оставлять coplanar задним граням камней (z-fighting) — утапливать глубже. Повороты scope (`rotateY` и т.п.) крутят вокруг **origin** scope (мин. угол бокса), а не вокруг центра — для колец/спиралей сначала `translate(size_x*0.5, ·, size_z*0.5)` origin'ом на ось, потом `repeat` + `rotateY(360·index/n)`; примитивы вписываются в scope-бокс (конус/сфера по границам), 2D-примитивы (`quad`/`polygon`) лежат в локальной плоскости x–z; `repeatNoPush` инкрементит атрибут `index` (0-based), на него можно вешать условные правила (`:: (index == 0)`) — так делается рампа цветов по ярусам.
