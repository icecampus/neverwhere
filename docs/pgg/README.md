# PGG — язык процедурной генерации геометрии

Вся документация по PGG собрана здесь.

| Документ | Содержание |
|---|---|
| `geometry_generation_language.md` | **Спецификация языка** — единственный источник правды по семантике: типы и атрибуты (§4), воспроизводимость и зоны (§5), синтаксис (§6), композиция (§7), builtin'ы (§8), отладка (§9), нодовая проекция (§10), диагностики (§11), этапы и критерии (§15), история изменений (§19) |
| `implementation.md` | **Заметки по реализации** — этапы E0–E8 по файлам (`src/libs/pgg`), инженерные грабли ANTLR/ядра, CLI PggTool и PggViewer, тестовый корпус `src/tests/pgg/corpus/` + продуктовые примеры `resources/pgg/` и сьюты тестов. Правя код PGG, обновляй его |
| `agent_tooling_plan.md` | **План работ: улучшение инструментов отладки для агента** — сервер `PggViewer --serve` + MCP `neverwhere-pgg` (картинка узла + статы + диагностики за один вызов по тёплому кэшу), нацеливание камеры, пробники `sample`/`slice`/`check`/`lattice`/`table[where]`/`--eval`, `--fingerprint`/`diff`/голдены-файлы, `docs builtin`/`--explain`, `--profile`; инциденты, приёмка, порядок и оценки |
| `mc_thin_shell_slivers.md` | **Расследование (закрыто, v1.24.2):** marching-cubes плавни-«бахрома» на тонкой оболочке призм — симптом, репрокейс, найденный корень (грань примитива ровно на узлах решётки `mesh_from_sdf`), фикс и тест |

Код: `src/libs/pgg` (библиотека), `src/apps/PggTool` (CLI), `src/apps/PggViewer` (нодовая проекция + превью), `src/tests/pgg` (тесты + корпус эталонов `.pgg`), `resources/pgg` (продуктовые/арт-примеры `.pgg` с модулями `lib/` и `cottage/`).
