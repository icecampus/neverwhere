# Voronoi - rocks

- Ссылка: https://www.shadertoy.com/view/MsXGzM
- Автор: iq (Inigo Quilez), 2013
- Источник: web.archive.org snapshot 2019-11-11 (код совпадает с живой версией — сверено с пастой пользователя)

**Лицензия:** в архивной (2019) версии — CC BY-NC-SA 3.0. В живой версии iq заменил хедер на
строгий (запрет хостинга/распространения/использования без пермиссии). Код идентичен;
храним архивную CC-версию с атрибуцией.

3D-voronoi (f2-f1) по текстурному LUT — скальные булыжники на полу, bump из tri-planar fbm,
curvature-occlusion. Камера-каталог вокруг сцены.

## Файлы

- `Image.glsl` — весь шейдер одним пассом (~6 КБ).
- `textures/iChannel0.png` — 256² RGBA, LUT случайных векторов для `random3f` (ветка `#if 1`;
  в коде есть `#else`-фолбэк на чистый хеш).
- `textures/iChannel3.jpg` — 512², текстура для `fbm` (tri-planar).
