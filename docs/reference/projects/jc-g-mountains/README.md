**Repository:** https://github.com/JC-G/Mountains  
**License:** (see repo)

## Summary

OpenGL **compute shader** terrain: 3D density grid from SDF, **marching cubes**, octree LOD chunks updated with camera.

## Fit for Neverwhere

- Generic volumetric terrain engine pattern (GPU field + MC)
- No geological fractures or LIRIS block structure
- Useful for future **GPU MC / chunked field** architecture
