# acfaruk / proc-rock

**Repository:** https://github.com/acfaruk/proc-rock  
**License:** GPL-3.0  
**Paper / thesis:** *Procedural Generation of Realistic-looking Rocks using Geological and Visual Clues*

## Summary

Desktop tool (GUI + CLI) for **individual rocks** mapped from geological categories (igneous, sedimentary, etc.) via node-based noise, boolean mesh ops, and implicit skin surfaces. Exports OBJ + PBR textures; reproducible JSON presets.

## Fit for Neverwhere

- Good for **scatter rocks / boulders**, not cliff-wall replication
- **GPL-3** — check compatibility before embedding in monorepo
- Different pipeline from Paris implicit blocks
