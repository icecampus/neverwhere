# gregorik / InstantOrganicCaves

**Repository:** https://github.com/gregorik/InstantOrganicCaves  
**License:** MIT (core GitHub version)

## Summary

Unreal Engine 5 plugin: **voxel grid → dynamic mesh** cave and rock structures at runtime. Pure C++ on `FDynamicMesh3`, chunk tiling, Laplacian smoothing, Nanite-ready output.

## Fit for Neverwhere

- Runtime **caves / organic voids**, not geologically typed block fractures
- UE-specific; ideas (chunked SDF/voxel, weld, smooth) transferable to Sokol path
- Commercial extended build on Fab (not in repo)
