# Автоматизация редактора (editor RPC + MCP)

_Вынесено из `AGENTS.md` (2026-09-06): корневой файл — компактная входная точка, подробности подсистем живут в `docs/`. Правя соответствующий код, обновляй **этот** документ._

EpicMapEditor поднимает TCP RPC-сервер на `127.0.0.1:9877` (построчный JSON, команды на GUI-потоке) — `src/apps/EpicMapEditor/src/editor_rpc_server.cpp`. Редактор должен быть запущен.

Операции:

- **Сессия:** `ping`, `status`, `list_chapters`, `load_chapter`, `create_chapter`, `save`, `reload`, `play`.
- **UI-стиль:** `list_assets`, `select_asset`, `select_tool`, `click` (экранные пиксели, зависит от камеры/зума).
- **Авторинг в координатах клеток** (идемпотентно, не зависит от камеры): `set_tile` / `erase_tile` / `fill_rect` (image-ассеты), `set_landscape` (bulk-апдейты нод `[[x,y,0|1],...]` на slice-ассете), `fence_stroke` (штрих забора `{asset_uuid, x, y, dirX, dirY, cells}` — тот же planStroke, что у кисти) / `erase_fence` (`{x, y, wholeFence}`) на fence3d-ассете, чтение — `get_map` (опц. `layer`), визуальная проверка — `set_camera` + `screenshot` (PNG). Грабли камеры: `set_camera` x/y — это **экранный offset в точках**, а не мировая точка (`worldToScreen = world*zoom + offset`); чтобы отцентрировать мировую (wx,wy) при зуме z: `x = viewW/2 − wx·z`, `y = viewH/2 − wy·z` (view ~717×806 pt). На macOS без Screen Recording-пермишена `grabWindow` либо падает, либо (хуже) отдаёт pixmap с вырезанным содержимым окна (видны окна под ним) — штатный обход: `screenshot` с `source="fbo"` (grabToImage самого render-item'а: тот же рендерер/z-буфер, но атласные полупрозрачные тайлы земли деградируют до «редких кустов на прозрачном», и окно поднимается на передний план — handler сам делает raise/activate и гоняет requestUpdate, иначе grab не дожидается кадра у скрытого окна).

Имена слоёв для оп: `Decoration` | `BaseLandscape` | `GameplayInteractive` | `RaisedLandscape` | `CliffLandscape` | `CyclopeanLandscape` | `StoneLandscape` | `TextureLandscape` | `TechLandscape` | `MaskLandscape` | `FenceLandscape` (enum `LayerTypes`). Запись идёт через `MapAuthoring` (`src/libs/core/map/map_authoring.h`), он же покрыт gtest (`src/tests/map/map_authoring_test.cpp`). `set_landscape` целится в слой по `layerType` ассета: slice-ассеты → `BaseLandscape`, shape3d-ассеты (поднятая 3D-земля) → `RaisedLandscape`, cliff3d-ассеты (клифы surface-nets) → `CliffLandscape`, cyclopean3d-ассеты (кладка landscape_mesh) → `CyclopeanLandscape`, stone3d-ассеты (вороной-камни `stone_gen::StoneField`) → `StoneLandscape`, texture2d-ассеты (тайлящиеся текстуры с блендом) → `TextureLandscape`, tech3d-ассеты (технический ленд Ridge/Valley `tech::TechField`) → `TechLandscape`, mask3d-ассеты (песчаный берег-плита с юбкой `mask::MaskField` + PBR-lite материал) → `MaskLandscape`, fence3d-ассеты (забор из печёных ShapeML-кусков `fence_core`) → `FenceLandscape` (для него — `fence_stroke`/`erase_fence`, не `set_landscape`).

MCP-обёртка: серверы `neverwhere-editor` (macOS) / `neverwhere-editor-win` в `.mcp.json`, код — `tools/editor_mcp/` (тонкий прокси, инструменты `editor_*`; TCP-клиент переиспользован из `tools/debug_mcp/editor_rpc_client.py`, пригоден и для ручных скриптов). Типовой цикл «карта по описанию»: `create_chapter`/`load_chapter` → `list_assets` → `set_landscape` → `fill_rect`/`set_tile` → `set_camera` + `screenshot` → `get_map` → `save` → `play`.
