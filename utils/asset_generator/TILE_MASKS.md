# Маски генерации тайлов

Этот документ определяет маски точек, используемые для генерации тайлов ландшафта, основываясь на алгоритме `generate_atlas.py` и перечислении `TileType`.

## Определения точек

Маска тайла состоит из 9 точек: 4 угла, 4 середины ребер и 1 центральная точка.
Обход по периметру выполняется по часовой стрелке, начиная с Левого угла. Центральная точка идет последней.

### Индексы маски

1.  **Левый (L)** - Индекс 0
2.  **Лево-Верх (LU)** - Индекс 1
3.  **Верхний (U)** - Индекс 2
4.  **Верхо-Прав (UR)** - Индекс 3
5.  **Правый (R)** - Индекс 4
6.  **Право-Низ (RD)** - Индекс 5
7.  **Нижний (D)** - Индекс 6
8.  **Низо-Лев (DL)** - Индекс 7
9.  **Центр (C)** - Индекс 8

## Структура маски

Маска задается массивом: `[L, LU, U, UR, R, RD, D, DL, C]`.
Высоты: `1` (Верх), `0` (Низ), `0.5` (Середина).

# Вариант 1: Вогнутый / Складка (Valley / Concave)

Этот способ разбиения характерен тем, что диагональ проводится от опущенных (низких) точек, создавая впадины или плоские участки. В данном варианте **Corner** тайлы имеют плоское основание, а **Lack** тайлы имеют вогнутую складку.

| TileType | Маска (Valley) | Описание |
| :--- | :--- | :--- |
| **Full** | `[1, 1, 1, 1, 1, 1, 1, 1, 1]` | Плоское плато. |
| **DownLack** | `[1, 1, 1, 1, 1, 0.5, 0, 0.5, 0.5]` | Складка вниз. Диагональ U-D. |
| **LeftLack** | `[0, 0.5, 1, 1, 1, 1, 1, 0.5, 0.5]` | Складка влево. Диагональ L-R. |
| **UpLack** | `[1, 0.5, 0, 0.5, 1, 1, 1, 1, 0.5]` | Складка вверх. Диагональ U-D. |
| **RightLack** | `[1, 1, 1, 0.5, 0, 0.5, 1, 1, 0.5]` | Складка вправо. Диагональ L-R. |
| **UpCorner** | `[0, 0.5, 1, 0.5, 0, 0, 0, 0, 0]` | Плоское дно с рампой к углу. |
| **RightCorner** | `[0, 0, 0, 0.5, 1, 0.5, 0, 0, 0]` | Плоское дно. |
| **DownCorner** | `[0, 0, 0, 0, 0, 0.5, 1, 0.5, 0]` | Плоское дно. |
| **LeftCorner** | `[1, 0.5, 0, 0, 0, 0, 0, 0.5, 0]` | Плоское дно. |
| **UpAndDownCorners** | `[0, 0.5, 1, 0.5, 0, 0.5, 1, 0.5, 0]` | **Глубокая канава** (Долина). Центр 0. |
| **LeftRightCorners** | `[1, 0.5, 0, 0.5, 1, 0.5, 0, 0.5, 0]` | **Глубокая канава** (Долина). Центр 0. |
| **Lines** | (См. общие) | Наклонные стены одинаковы в обоих вариантах. |

# Вариант 2: Выпуклый / Гребень (Ridge / Convex) - Текущий

Этот способ разбиения характерен тем, что диагональ проводится между поднятыми (высокими) точками, создавая гребни и выпуклости. **Corner** тайлы становятся пиками с хребтом к центру, а **Lack** тайлы (если бы использовался этот метод) стали бы плоскими плато.
**В текущей реализации для Lack используется логика Valley (для красоты), но для Corner используется логика Ridge.**

Ниже приведена полная таблица для "чистого" варианта Ridge, а также гибридный вариант, используемый сейчас.

## Чистый Ridge (Все выпуклое)
В этом варианте Lack тайлы были бы плоскими сверху (центр = 1), а Corner тайлы выпуклыми.

## Гибридный (RPG Style) - Используется в Atlas Generator
Смесь: **Lack** тайлы вогнутые (Valley, центр 0.5), **Corner** тайлы выпуклые (Ridge, центр 0.5), **Opposite** тайлы седловидные (Saddle, центр 0.5).

| TileType | Маска (Hybrid / Current) | Описание реализации |
| :--- | :--- | :--- |
| **Full** | `[1, 1, 1, 1, 1, 1, 1, 1, 1]` | Плоское плато. |
| **DownLack** | `[1, 1, 1, 1, 1, 0.5, 0, 0.5, 0.5]` | **Valley**: Складка. Диагональ U-D. |
| **LeftLack** | `[0, 0.5, 1, 1, 1, 1, 1, 0.5, 0.5]` | **Valley**: Складка. Диагональ L-R. |
| **UpLack** | `[1, 0.5, 0, 0.5, 1, 1, 1, 1, 0.5]` | **Valley**: Складка. Диагональ U-D. |
| **RightLack** | `[1, 1, 1, 0.5, 0, 0.5, 1, 1, 0.5]` | **Valley**: Складка. Диагональ L-R. |
| **UpCorner** | `[0, 0.5, 1, 0.5, 0, 0, 0, 0, 0.5]` | **Ridge**: Выпуклый пик. Диагональ U-D. |
| **RightCorner** | `[0, 0, 0, 0.5, 1, 0.5, 0, 0, 0.5]` | **Ridge**: Выпуклый пик. Диагональ L-R. |
| **DownCorner** | `[0, 0, 0, 0, 0, 0.5, 1, 0.5, 0.5]` | **Ridge**: Выпуклый пик. Диагональ U-D. |
| **LeftCorner** | `[1, 0.5, 0, 0, 0, 0, 0, 0.5, 0.5]` | **Ridge**: Выпуклый пик. Диагональ L-R. |
| **RightUpLine** | `[0, 0.5, 1, 1, 1, 0.5, 0, 0, 0.5]` | Стена U-R. |
| **RightDownLine** | `[0, 0, 0, 0.5, 1, 1, 1, 0.5, 0.5]` | Стена R-D. |
| **LeftDownLine** | `[1, 0.5, 0, 0, 0, 0.5, 1, 1, 0.5]` | Стена L-D. |
| **LeftUpLine** | `[1, 1, 1, 0.5, 0, 0, 0, 0.5, 0.5]` | Стена L-U. |
| **UpAndDownCorners** | `[0, 0.5, 1, 0.5, 0, 0.5, 1, 0.5, 0.5]` | **Saddle**: Седловидная. Центр 0.5. |
| **LeftRightCorners** | `[1, 0.5, 0, 0.5, 1, 0.5, 0, 0.5, 0.5]` | **Saddle**: Седловидная. Центр 0.5. |
| **Unknown** | `[0, 0, 0, 0, 0, 0, 0, 0, 0]` | - |
