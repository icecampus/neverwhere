# Маски генерации тайлов

Этот документ определяет маски точек, используемые для генерации тайлов ландшафта, основываясь на алгоритме `generate_atlas.py` и перечислении `TileType`.

## Определения точек

Маска тайла состоит из 9 точек: 4 угла, 4 середины ребер и 1 центральная точка.
Обход по периметру выполняется по часовой стрелке, начиная с Левого угла. Центральная точка идет последней.

### Индексы маски

1.  **Левый (L)** - Индекс 0 (Угол)
2.  **Лево-Верх (LU)** - Индекс 1 (Середина ребра)
3.  **Верхний (U)** - Индекс 2 (Угол)
4.  **Верхо-Прав (UR)** - Индекс 3 (Середина ребра)
5.  **Правый (R)** - Индекс 4 (Угол)
6.  **Право-Низ (RD)** - Индекс 5 (Середина ребра)
7.  **Нижний (D)** - Индекс 6 (Угол)
8.  **Низо-Лев (DL)** - Индекс 7 (Середина ребра)
9.  **Центр (C)** - Индекс 8 (Центр клетки)

## Структура маски

Маска задается массивом: `[L, LU, U, UR, R, RD, D, DL, C]`.

Значения высоты:
*   `1`: Точка поднята (Верхний уровень).
*   `0`: Точка опущена (Базовый уровень).
*   `0.5`: Точка на середине склона.

### Правило триангуляции "Lack" тайлов

Тайлы типа `*Lack` имеют 3 поднятых угла и 1 опущенный. Такие фигуры не являются плоскими, и результат зависит от способа разбиения четырехугольника на треугольники.

В данной системе принят следующий стандарт триангуляции:
**Ребро разбиения (диагональ) должно проходить от опущенной вершины к противоположной поднятой.**

*   Это создает "вогнутую" форму (складку), где центр находится на высоте `0.5`.
*   Альтернативный способ (соединение двух поднятых вершин) создал бы плоскую "крышку" с центром на высоте `1.0`, что выглядит некорректно для ландшафта.

Поэтому:
*   **DownLack** и **UpLack** разбиваются вертикально (диагональ U-D).
*   **LeftLack** и **RightLack** разбиваются горизонтально (диагональ L-R).

## Определения тайлов

| TileType | Маска [L, LU, U, UR, R, RD, D, DL, C] | Примечание |
| :--- | :---: | :--- |
| **Full** | `[1, 1, 1, 1, 1, 1, 1, 1, 1]` | Плоская вершина. |
| **DownLack** | `[1, 1, 1, 1, 1, 0.5, 0, 0.5, 0.5]` | Угол D опущен. Диагональ U-D. |
| **LeftLack** | `[0, 0.5, 1, 1, 1, 1, 1, 0.5, 0.5]` | Угол L опущен. Диагональ L-R. (Центр=0.5) |
| **UpLack** | `[1, 0.5, 0, 0.5, 1, 1, 1, 1, 0.5]` | Угол U опущен. Диагональ U-D. |
| **RightLack** | `[1, 1, 1, 0.5, 0, 0.5, 1, 1, 0.5]` | Угол R опущен. Диагональ L-R. (Центр=0.5) |
| **UpCorner** | `[0, 0.5, 1, 0.5, 0, 0, 0, 0, 0]` | Пик в U. Диагональ U-D. (Центр=0.5) |
| **RightCorner** | `[0, 0, 0, 0.5, 1, 0.5, 0, 0, 0]` | Пик в R. Диагональ L-R. (Центр=0.5) |
| **DownCorner** | `[0, 0, 0, 0, 0, 0.5, 1, 0.5, 0]` | Пик в D. Диагональ U-D. (Центр=0.5) |
| **LeftCorner** | `[1, 0.5, 0, 0, 0, 0, 0, 0.5, 0]` | Пик в L. Диагональ L-R. (Центр=0.5) |
| **RightUpLine** | `[0, 0.5, 1, 1, 1, 0.5, 0, 0, 0.5]` | Стена U-R. |
| **RightDownLine** | `[0, 0, 0, 0.5, 1, 1, 1, 0.5, 0.5]` | Стена R-D. |
| **LeftDownLine** | `[1, 0.5, 0, 0, 0, 0.5, 1, 1, 0.5]` | Стена L-D. |
| **LeftUpLine** | `[1, 1, 1, 0.5, 0, 0, 0, 0.5, 0.5]` | Стена L-U. |
| **UpAndDownCorners** | `[0, 0.5, 1, 0.5, 0, 0.5, 1, 0.5, 0.5]` | Хребет U-D. Центр (0.5). |
| **LeftRightCorners** | `[1, 0.5, 0, 0.5, 1, 0.5, 0, 0.5, 0.5]` | Два пика L и R. Центр (0.5). |
| **Unknown** | `[0, 0, 0, 0, 0, 0, 0, 0, 0]` | - |
