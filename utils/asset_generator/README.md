# Генератор Технического Атласа (Technical Atlas Generator)

Этот скрипт генерирует текстурный атлас для изометрических тайлов ландшафта. Он создает визуализацию различных типов тайлов (углы, склоны, ровные участки) с просчетом освещения и наложением "почвы" (боковых стенок).

## Возможности

*   **Изометрическая проекция**: Генерирует тайлы в правильной изометрической проекции (соотношение сторон 2:1).
*   **Освещение**: Рассчитывает простое направленное освещение для граней тайлов на основе их нормалей.
*   **Типология**: Поддерживает множество конфигураций тайлов (Full, Corners, Lacks, Lines и т.д.), определенных через маски высот.
*   **Визуализация**: Рисует зеленую поверхность ("траву") и коричневые боковые стенки ("почву").
*   **Отладка**: Наносит ID и название типа тайла прямо на изображение.

## Как использовать

Скрипт можно запустить без аргументов (результат сохранится в текущей папке как `technical_atlas.png`) или указать путь для сохранения файла.

### Примеры запуска

1.  **Базовый запуск** (сохранит `technical_atlas.png` в папке запуска):
    ```bash
    python utils/asset_generator/generate_atlas.py
    ```

2.  **Указание пути сохранения** (сохранит файл по указанному пути):
    ```bash
    python utils/asset_generator/generate_atlas.py resources/assets/landscape/TechnicalGrass/atlas.png
    ```

## Зависимости

Для работы скрипта требуется библиотека `Pillow` (PIL).
Если она не установлена:
```bash
pip install Pillow
```
