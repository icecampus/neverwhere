# Генераторы атласов ландшафта (разделены на ветки)

Чтобы **не ломать существующее** и при этом экспериментировать, генераторы разделены на 2 независимые ветки:

- **`technical/`**: стабильные “технические” генераторы (как было раньше) — маски/триангуляция/освещение.
- **`material/`**: экспериментальные генераторы “материалов” (композитинг текстур, мягкие края, декали).

## Быстрые ссылки

- Technical: `utils/asset_generator/technical/README.md`
- Material: `utils/asset_generator/material/README.md`

## Совместимость

В корне `utils/asset_generator/` сохранены “старые” имена файлов, чтобы команды из истории/доков продолжали работать.
Они считаются **shim/compat wrappers** и перенаправляют запуск в `technical/` или `material/`.

## Зависимости

Для работы скрипта требуется библиотека `Pillow` (PIL).
Если она не установлена:
```bash
pip install Pillow
```
