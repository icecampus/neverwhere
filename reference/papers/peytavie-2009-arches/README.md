## Code

**No public release** of the original Arches modeling application. Later LIRIS work was reimplemented in:

- https://github.com/aparis69/Implicit-Volumetric-Terrains (2019, partial)
- Internal “Arches platform” (see https://perso.liris.cnrs.fr/apeytavi/website/code/)

## What it covers

- Hybrid model: **material layers** (volumetric) + **implicit surface** for sculpting
- Overhangs, **arches**, caves; sand vs rock materials
- High-level authoring tools; procedural rock piles without heavy physics

## Role in the research line

Conceptual predecessor to Paris 2019 TOG and Paris 2020 TVC. Useful for terminology (layers, implicit sculpting) even without code.
