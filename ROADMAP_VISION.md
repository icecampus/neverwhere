# Стратегическое виденье и позиционирование

**Neverwhere** — это узкоспециализированный 2D engine/suite: **Epic Map Editor** (редактор) + **EpicGameRuntime** (runtime-клиент). Редактор создаёт и редактирует игровые данные, runtime запускает “тот же мир” для проверки и плейтеста.

## 🎯 Позиционирование
**Epic Map Editor** задуман как специализированная платформа для создания системных 2D-игр (System-driven games). Мы занимаем нишу "Золотой середины":
*   Гибче и мощнее, чем **RPG Maker** (не ограничены жанром JRPG и тайловой сеткой одного слоя).
*   Удобнее и быстрее, чем **Unity/Godot** (предоставляем готовые высокоуровневые инструменты для жанра "из коробки", а не заставляем писать инвентарь с нуля).

**Целевые жанры:**
*   Farming Sims / Симуляторы жизни (Stardew Valley, Harvest Moon).
*   Action-RPG / Hack-and-Slash (Diablo, Torchlight).
*   Менеджмент и экономические стратегии (Graveyard Keeper).
*   Рогалики (Roguelikes).

## 🚀 Ключевые возможности (Vision Pillars)

### 1. Бесшовный рабочий процесс (Seamless Workflow)
*   **Мгновенный Play-Test:** Запуск уровня/главы прямо из редактора через **EpicGameRuntime**. Камера/точка старта фокусируется там же, где был редактор.
*   **Горячая перезагрузка:** Возможность менять параметры баланса на лету, не перезапуская runtime.
*   **Fixtures для игровых данных:** если runtime-логике нужны данные, которых нет в текущей карте (профиль игрока, прогресс, инвентарь), редактор подсовывает их как **фикстуры** (по аналогии с unit tests): “профиль по умолчанию”, “тестовый инвентарь”, временное in-memory хранилище на время сессии плейтеста.

### 2. Визуальное превосходство ландшафта (Advanced Landscape)
*   **Многослойность:** Поддержка множества слоев высоты и тайлов.
*   **Smart Blending:** Продвинутая система смешивания материалов (авто-переходы песок -> трава -> камень) без видимых швов.
*   **Авто-декорирование:** Процедурная кисть для нанесения декалей (камни, цветы, трещины) и вариаций тайлов, чтобы избежать "тайлового шума".

### 3. Глубокая процедурная генерация (Deep Generation)
*   **Генерация Смысла, а не только шума:** Генератор создает не просто карту высот, а логически связные структуры (деревня с жителями, подземелье с боссом).
*   **Вплетение сюжета:** Автоматическое размещение квестовых NPC и предметов в сгенерированном мире.
*   **Indoor/Outdoor:** Поддержка бесшовной генерации интерьеров зданий внутри глобальной карты мира.

### 4. "Живой Мир": Атмосфера и Время
*   **Timeline-режиссер:** Инструмент для настройки суточного цикла и погоды. "В 19:00 включить фонари, изменить тон освещения, запустить звук сверчков".
*   **Динамическое освещение 2D:** Зоны света, тени от объектов, реагирующие на время суток.

### 5. Поведение и Расписание (Behavior & Schedules)
*   **Редактор жизни NPC:** Визуальная шкала расписания для симуляторов жизни (Утро: Дом -> Работа; Вечер: Таверна).
*   **AI Patterns:** Конструктор поведения врагов для Action-RPG (Видит игрока -> Атака; Мало HP -> Побег) без написания кода.

### 6. База Данных Сущностей (Entity Database)
*   **Табличный редактор баланса:** Встроенный аналог Excel для управления тысячами предметов.
*   **Наследование:** Создание архетипов ("Базовый Меч") и вариаций ("Огненный Меч +1").
*   **Визуальный Лут:** Настройка таблиц выпадения предметов (Drop Tables) с визуализацией вероятностей.

### 7. Интерактивность "Из коробки"
*   **Destructible & Harvestable:** Система разрушаемого окружения (рубка деревьев, разбивание бочек) на уровне галочки в свойствах объекта. Не нужно программировать получение урона для каждого куста.

### 8. Нарративный Дизайн (Quests & Dialogs)
*   **Нодовый редактор диалогов:** Графы диалогов с условиями (проверка инвентаря, отношений).
*   **Smart Flow:** Визуализация переходов между локациями (телепорты, двери) в виде связей, где видно превью целевой локации.
